# Raster Explorer

A single-page Quarto book with a full-screen Leaflet raster map and an expandable information panel. Its charcoal, green, Cosmo-inspired styling and GECO logo are adapted from the [GECO R book template](https://github.com/geco-bern/R_book_template).

## Preview locally

```bash
quarto preview
```

## Build

```bash
quarto render
```

The rendered website is written to `_site/`.
